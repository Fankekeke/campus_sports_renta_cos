# 基于 SpringBoot + Vue 的校园运动器械租借系统

租借下单 · 信用积分 · 在线支付 · 订单评价 · 器械全生命周期 · 采购维修 · 邮件提醒 · 双端协同

本项目是一套面向高校场景的轻量级运动器械租借管理平台，采用前后端分离架构，覆盖**管理员、用户（学生/教职工）**两类角色。系统围绕"器械管理、租借订单、信用积分、在线支付、订单评价、器械采购、器械维修、消息通知、邮件提醒、数据统计"等核心业务设计，支持从用户浏览器械、在线租借、在线支付、归还核销、信用积分变动，到管理员器械全生命周期管理（采购→入库→租借→归还→维修→报废）、供应商管理、订单评价审核、数据统计看板的全链路数字化运营，同时融入信用积分体系与邮件提醒机制，引导用户文明使用器械，提升校园体育资源管理效率与服务体验。

## 核心特性

- **双角色权限体系**：区分管理员与用户（学生/教职工），基于 RBAC 模型实现功能权限与数据权限控制，管理员负责器械全生命周期管理与平台运维，用户专注于器械租借与个人事务。
- **完整租借闭环**：覆盖"浏览器械→选择时段→提交租借→在线支付→取用器械→归还核销→订单评价"全流程，订单状态机涵盖待支付、待取用、租借中、已归还、已取消、已逾期、已退款等状态，状态流转全程留痕。
- **信用积分体系**：建立用户运动诚信档案，初始信用分 100 分，按时归还加分、逾期归还扣分、器材损坏瞒报重扣，信用分低于阈值暂停租借权限，高于阈值享受免押金特权，积分变动明细全程可追溯。
- **器械全生命周期管理**：覆盖器械采购入库、分类管理、库存维护、租借流转、归还核销、维修登记、报废处理全流程，每件器械状态（可用/租借中/维修中/报废）实时更新，库存预警自动提醒采购。
- **在线支付与邮件提醒**：集成支付宝在线支付，支持订单支付、押金缴纳与退还；关键节点（租借成功、归还提醒、逾期催还、支付确认）自动发送邮件提醒，防止用户遗忘。
- **订单评价与信用联动**：用户完成订单后可对器械与服务进行评分与文字评价，评价数据参与器械热度排序，差评自动触发管理员关注，形成"租借—评价—改进"良性循环。
- **数据统计看板**：管理员端提供多维度数据统计，包括器械周转率、租借订单趋势、热门器械排行、信用积分分布、营收统计、维修成本分析等，支持图表可视化展示。

## 功能模块概览

## 管理员端

管理员为平台核心运营角色，负责器械全生命周期管理与平台运维：

### 账号与基础

- **账户登录**：支持管理员账号密码登录，支持修改密码与安全设置，登录日志全程记录。
- **员工管理**：管理后台操作员账号，包括姓名、工号、角色（超级管理员/普通管理员）、权限范围、最后登录时间，支持账号启用/禁用。
- **用户管理**：管理注册用户信息，包括姓名、学号/工号、手机号、邮箱、信用积分、账户状态，支持用户账号冻结/解冻与信用分人工调整。

### 器械管理

- **器械类型**：管理器械分类，包括分类名称、图标、排序、描述，支持多级分类（如球类、健身器械、户外装备、防护装备等）。
- **器械管理**：管理器械档案，包括器械名称、图片、分类、品牌、规格、库存数量、可借数量、存放位置、租金（按时长阶梯计价）、押金、描述、上下架状态，支持批量导入与库存预警设置。
- **供应商管理**：管理器械供应商信息，包括供应商名称、联系人、联系方式、地址、供应品类、合作状态，支持供应商评估与采购关联。
- **器械采购**：管理器械采购流程，包括采购申请、审批、入库登记，记录采购器械、数量、单价、供应商、采购日期、入库状态，支持采购数据统计与成本核算。
- **器械维修**：管理器械维修工单，包括报修器械、故障描述、维修状态（待维修/维修中/已完成）、维修费用、维修日期、维修人员，维修期间器械自动标记为不可借。

### 订单与财务

- **租借订单**：查看平台全部租借订单，包括订单号、用户信息、器械明细、租借时段、订单金额、订单状态（待支付/待取用/租借中/已归还/已取消/已逾期），支持订单筛选、手动核销归还、取消订单、处理退款。
- **支付记录**：查看平台全部支付记录，包括订单号、支付金额、支付方式（支付宝）、支付状态、支付时间、交易流水号，支持财务对账与报表导出。
- **信用积分记录**：查看用户信用积分变动明细，包括变动时间、变动分值、变动事由（按时归还/逾期/损坏等）、关联订单，支持信用分人工调整与信用修复审核。

### 内容与互动

- **公告信息**：发布与管理平台公告，包括公告标题、内容、类型（通知/活动/维护）、发布时间、置顶状态，支持公告编辑与删除，用户端首页展示最新公告。
- **消息通知**：管理站内消息，包括订单通知、归还提醒、逾期催还、系统公告等，支持向指定用户或全员推送消息，消息记录可追溯。
- **订单评价**：查看用户提交的订单评价，包括评分、评价内容、关联订单，支持评价审核（隐藏违规评价）与管理员回复。

### 数据统计

- **数据统计**：综合数据看板，展示核心运营指标（今日租借量/营收/新增用户/器械可用率），支持器械周转率分析、热门器械排行、租借时段热度分析、信用积分分布、营收与成本分析等多维度图表展示，支持报表导出。

## 用户端（学生/教职工）

用户为平台的器械租借消费者，提供完整的租借下单与个人事务管理功能：

### 账号与个人

- **账户注册登录**：支持手机号+验证码注册登录、账号密码登录，支持找回密码，首次登录自动创建用户档案并分配初始信用分（100 分）。
- **密码修改**：支持用户自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括姓名、学号/工号、手机号、邮箱、头像，支持查看个人信用积分与租借历史。

### 租借与订单

- **器械浏览**：浏览平台器械列表，支持按分类、价格、库存、热度筛选，查看器械详情（图片、名称、分类、规格、租金、押金、库存、描述、用户评价），支持收藏器械。
- **我的订单**：查看本人全部租借订单，包括订单号、器械明细、租借时段、订单金额、订单状态（待付款/待取用/租借中/已归还/已取消/已逾期），支持订单筛选、取消待付款订单、申请退款、确认归还。
- **在线支付**：对待付款订单进行支付宝在线支付，支持租金与押金缴纳，支付成功后自动更新订单状态并通知管理员，归还后押金自动原路退还。
- **支付记录**：查看个人全部支付记录，包括订单号、支付金额、支付方式、支付状态、支付时间，支持支付明细查询。

### 信用与评价

- **信用积分**：查看个人信用积分与变动明细，包括当前分值、变动记录（时间、事由、分值变化）、信用等级，了解信用分规则与权益（如免押金特权）。
- **订单评价**：对已归还订单进行评价，包括器械评分、服务评分、评价内容，评价提交后不可修改，支持查看历史评价记录。

### 消息与提醒

- **我的消息**：查看个人收到的所有站内消息，包括订单通知、归还提醒、逾期催还、系统公告等，支持已读/未读管理与消息搜索。
- **邮件提醒**：绑定个人邮箱，关键节点（租借成功、归还前 30 分钟预警、逾期催还、支付确认、押金退还）自动发送邮件提醒，防止遗忘。
